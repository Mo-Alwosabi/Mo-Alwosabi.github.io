# AGENTS.md

## Project Context
Multilingual static portfolio built with Astro 5, Preact, Tailwind CSS, GSAP, and AOS (`en` and `de` locales).

## Commands
- Install: `npm install`
- Dev server: `npm run dev`
- Build: `npm run build`
- Preview: `npm run preview`

## Conventions
- Keep Astro/Tailwind/i18n structure intact.
- Consult `CODEBASE_MAP.md` before adding routes, components, or utilities.
