# Mohammed Ameen Al-Wosabi — Portfolio

Personal multilingual portfolio (**English** & **Arabic RTL**) built with **Astro**, **Preact**, **Tailwind CSS**, and a WebGL2 interactive **SwarmCursor** background.

Live Site: [https://mo-alwosabi.github.io/](https://mo-alwosabi.github.io/)

## Features
- **Multilingual (EN / AR)**: English default (`/`) and full Right-to-Left Arabic (`/ar/`).
- **Interactive WebGL2 Background**: Custom `SwarmCursor` particle simulation with dark/light theme synchronization and click-burst effect.
- **Dark & Light Mode**: Persistent theme toggle with smooth transitions.
- **Sections**: Hero, About Me, 9-category Skills & Technologies grid, Academic & Professional Journey timeline, and obfuscated Contact cards.

## Tech Stack
- [Astro 5](https://astro.build/) (Static Site Generation)
- [Preact](https://preactjs.com/) (`@astrojs/preact`)
- [Tailwind CSS](https://tailwindcss.com/)
- [GSAP](https://gsap.com/) & [AOS](https://michalsnik.github.io/aos/)
- [Lucide Icons](https://lucide.dev/)

## Local Development
```bash
npm install
npm run dev
```

## Build & Deploy
```bash
npm run build
```
The built static output in `dist/` is deployed to the `gh-pages` branch (with `.nojekyll` included for `_astro/` assets).
